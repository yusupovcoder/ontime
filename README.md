# On Time

Планировщик для студентов на трёх языках (русский, узбекский, английский): дедлайны, календарь сдач, расписание пар, таймер учёбы и оценки. Показывает, что горит, ведёт обратный отсчёт до ближайшей сдачи и помогает разбить большие работы на шаги.

## Что умеет

- Задания с предметом, типом работы, датой и временем сдачи
- Группы по срочности: просрочено, сегодня и завтра, ближайшие 7 дней, позже, сдано
- Обратный отсчёт до ближайшего дедлайна
- Шаги внутри задания с прогрессом и планом «к какому дню делать каждый шаг»
- «Подсказать шаги»: типовые этапы для реферата, курсовой, лабы, экзамена и других работ
- Календарь на месяц: видно, где скапливаются сдачи
- Расписание пар (вносится вручную): чётные и нечётные недели, аудитории, строка «Сейчас идёт / следующая пара», напоминание, если по предмету в этот день что-то сдавать
- Предметы с цветами и фильтр по ним
- Фокус: таймер помодоро с кольцом, режимами (фокус, перерыв, длинный перерыв), выбором предмета и звуком; статистика за неделю по дням и предметам
- Оценки: средний балл общий и по предметам, текущие, контрольные и экзамены, подсчёт троек и двоек, расчёт «сколько пятёрок нужно до цели»
- Оформление: светлая, тёмная или авто тема и 5 цветов акцента
- Языки: русский, Oʻzbekcha (латиница), English. Язык определяется по браузеру и меняется в настройках; даты, числа, примеры, подсказки шагов и политика конфиденциальности переводятся вместе с интерфейсом
- Резервная копия в файл, загрузка из файла, удаление всех данных
- Интерфейс в стиле iOS 26 с Liquid Glass: плавающая стеклянная панель вкладок, стеклянные кнопки, меню и шторки, крупные заголовки, переключатели
- Светлая и тёмная тема (по настройке системы)

## Как запустить

1. Открой папку в VS Code: **File → Open Folder…**
2. Установи расширение **Live Server** (VS Code сам предложит его из рекомендаций).
3. Нажми правой кнопкой на `index.html` → **Open with Live Server**.

Можно и без расширения: открой `index.html` двойным кликом в браузере.

> Live Server вставляет в страницу свой скрипт автообновления, а защита CSP его блокирует. В консоли браузера может появиться ошибка `Refused to execute inline script`. Приложение при этом работает нормально, просто после правок обновляй страницу вручную (F5).

## Android (APK)
Приложение упаковано в Android через Capacitor 8: та же папка `www/` открывается во встроенном WebView, без сети. В Android-версии есть напоминания о сдачах и об окончании таймера (Настройки → Уведомления), системная кнопка «Назад», экспорт через «Поделиться» и максимальная частота экрана.

**Вариант 1 — без установки программ (GitHub Actions):**
1. Создайте пустой репозиторий на github.com (кнопка New → имя `on-time` → Create).
2. «uploading an existing file» → перетащите всё из этой папки, **кроме** `node_modules` и `android` → Commit.
3. Ещё раз Add file → Upload files → перетащите папку `android` целиком → Commit (у GitHub лимит 100 файлов за раз, поэтому в два захода).
4. Вкладка **Actions** → «Android APK» → **Run workflow**. Через ~5–7 минут откройте запуск → внизу **Artifacts** → `on-time-debug-apk` (zip с `app-debug.apk`).
5. Скиньте APK на телефон, откройте, разрешите «Установка из неизвестных источников».

**Вариант 2 — на своём компьютере (Android Studio):**
1. Установите Node.js 22 и Android Studio (в нём есть JDK 21 и Android SDK).
2. В этой папке: `npm install`, затем `npm run sync`, затем `npm run open`.
3. В Android Studio: Build → Generate App Bundles or APKs → Build APK(s). Файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

После правок в `www/` всегда выполняйте `npx cap sync android` (в GitHub Actions это делается само).

**Подпись и обновления.** В Settings → Secrets and variables → Actions репозитория должны быть два секрета: `ONTIME_KEYSTORE_BASE64` (ключ `on-time-release.jks` в base64) и `ONTIME_KEYSTORE_PASSWORD`. Тогда каждый push в main собирает подписанный APK (+ AAB для Google Play) и выкладывает его в Releases как `on-time.apk` — постоянная ссылка `https://github.com/yusupovcoder/ontime/releases/latest/download/on-time.apk`. Номер сборки = 100 + номер запуска, поэтому новые версии ставятся поверх старых, а приложение находит их кнопкой «Проверить обновление» (Настройки → Обновления) и при запуске. Ключ и пароль храните отдельно и надёжно: без них обновить установленное приложение будет нельзя. Без секретов собирается только отладочный APK (Actions → Artifacts).

Иконка и заставка: `node assets/make-icons.js`, затем `npm run icons`.

## Где хранятся данные

В `localStorage` браузера на этом устройстве. Никуда не отправляются. Подробнее — в [PRIVACY.md](PRIVACY.md).

## Безопасность

- **XSS.** Весь пользовательский текст проходит через `esc()` перед выводом в HTML.
- **Проверка данных.** Всё, что читается из хранилища или из файла, проходит через `sanitize()`: неизвестные поля отбрасываются, id, даты, время, цвета и типы сверяются с допустимыми значениями, длина строк и число записей ограничены (`LIMITS`).
- **Импорт.** Файл больше 2 МБ отклоняется. Перед заменой данных показывается, сколько в файле заданий, предметов и пар, и нужно подтверждение.
- **CSP.** `index.html` разрешает загружать только файлы самого приложения: никаких сторонних скриптов, шрифтов и сетевых запросов.
- **Без сторонних сервисов.** Используется системный шрифт устройства, аналитики и рекламы нет.
- **Ограничение.** `localStorage` не шифруется. Не храни в приложении пароли и документы.

## Автотест
`tests/android-test.js` — проверяет Android-ветки (кнопка «Назад», экспорт через «Поделиться», цвет строки состояния) с подменённым мостом Capacitor.


В папке `tests/` три проверки (Playwright):

- `full-test.js` — все кнопки и действия на русском (255 проверок): вкладки, задания, шаги, формы, календарь, пары, фокус, оценки, оформление, резервная копия, защита от вредных файлов, вёрстка от 320 до 1280 px;
- `lang-test.js` — английский и узбекский (47 проверок): нет ли русского текста на всех экранах, в шторках и меню, форматы дат и чисел, переключение языка, автоопределение;
- `cloud-test.js` — сохранение в аккаунт на claude.ai (на имитации платформы).

```
npm install playwright
npx playwright install chromium
python -m http.server 8765        # в папке проекта, в отдельном терминале
node tests/full-test.js
node tests/lang-test.js
node tests/cloud-test.js
```
